# InventarisLabWeb
Laboratory Tools Maintenance Web is a web-based application for managing laboratory equipment borrowing efficiently. It provides features such as data input and management, borrowing time estimation, deadline monitoring, and late return detection. Built with JavaScript, Tailwind CSS, and Supabase to ensure structured and real-time data handling. 

A web-based application for managing laboratory equipment borrowing efficiently and in a structured way.

## ✨ Features
- Input and manage borrowing data (Name, Department, Item, Time, Condition)
- Borrowing time estimation (deadline system)
- Edit and manage user data
- Automatic data removal after borrowing is completed
- Monitoring approaching deadlines
- Detect and filter late returns
- Clean dashboard for tracking usage

## 🛠️ Tech Stack
- JavaScript
- Tailwind CSS
- Supabase

## 🎯 Purpose
This system is built to improve laboratory equipment management, reduce data loss, and provide real-time monitoring for borrowing activities.
